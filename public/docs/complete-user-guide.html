02

Core Controls & Input Box Dictionary

Detailed breakdown of every input, button, and parameter

BOX Raw Script / Idea Box Location: Left Primary Panel

Purpose: Primary input box for pasting raw ideas, rough thoughts, article snippets, or YouTube transcripts.
Best Practice: You don't need clean formatting. Even broken notes, bullet points, or stream-of-consciousness ideas will be systematically restructured into viral scripts.

BUTTON Paste / Clear / Sample Preset Header of Input Box

Paste: Injects your device clipboard with one click.
Clear: Wipes the slate clean for a fresh project.
Sample: Loads a high-performing real-world script prompt to instantly test the engine.

DROPDOWN Domain / Topic Niche (50+ Categories) Parameters Sidebar

Purpose: Grounds the AI in domain-specific terminology, audience expectations, and technical context (e.g. AI, Finance, History, Gaming, Islamic, Civil Engineering, Healthcare).

TOGGLE Hooks, Body & Conclusion Enforcer Recommended: Always ON

Purpose: Mandates the 3-phase viral video formula: 0-5s Hook pattern interrupt → Value Body delivery → Natural call-to-action (CTA).

Prompting & Command Masterclass

How to write inputs that generate 10/10 viral outputs

Template A: Tech Shorts / Reels
"Topic: Why Quantum Computers will make regular encryption obsolete in 2026.
Tone: Fast Paced Explainer
Target: 140 words, high curiosity hook."

Expected Output: High-energy opening, simple qubit metaphor, visual B-roll cues, subscribe CTA.

Template B: Mystery / Documentary
"Topic: The mystery of flight MH370 radar anomaly.
Tone: Dramatic Narrative
Voice Persona: Deep Documentary Narrator
Length: 800 words."

Expected Output: Atmospheric pacing, suspense pauses, radar timestamps, cinematic visual directions.
