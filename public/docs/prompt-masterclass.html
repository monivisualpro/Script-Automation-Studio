01. The Anatomy of a High-Retention Script

1. THE HOOK (0:00 - 0:05)

Pattern interrupt that breaks boredom and stops the user from scrolling.

2. THE PROMISE (0:05 - 0:15)

Stakes & relevance: Tells the viewer why watching till the end pays off.

3. VALUE DELIVERY (Body)

Fast, rhythmic information chunks paired with vivid visual B-roll cues.

4. CALL TO ACTION (CTA)

Natural question prompt or subscription incentive that boosts comments.

02. Copy-and-Paste Ready Input Blueprints

TOP 5 / LISTICLE VIDEO PROMPT Target: Tech / Productivity 
Topic: Top 5 AI tools every student must use in 2026.
Key Points:
1. Perplexity AI for deep research.
2. Gemini Advanced for document summaries.
3. Gamma App for instant slides.
4. Notion AI for task management.
5. Otter.ai for lecture recording.
Goal: Make it fast-paced with high curiosity. Include B-roll suggestions for screen recordings.
STORYTELLING / CASE STUDY PROMPT Target: Business / Documentary 
Topic: How Airbnb survived 2008 without going bankrupt.
Angle: The famous cereal box hustle (Obama O's).
Tone: Deep documentary narrative with suspense.
Structure: Start in the middle of crisis, reveal secret strategy, end with modern lesson.
SPIRITUAL / ISLAMIC REMINDER PROMPT Target: YouTube Shorts / Vlogs 
Topic: The importance of patience (Sabr) during difficult times.
Tone: Warm, empathetic, and comforting.
Language: Roman Urdu / Hindi with English subtitles formatting.
Greetings Prefix: Assalamualaikum.
Goal: Provide actionable spiritual peace.
